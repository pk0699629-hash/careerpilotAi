# CareerPilotAI 🚀

An AI-powered career guidance web application designed to help users explore career opportunities, identify skill gaps, create learning roadmaps, and prepare for their professional journey.

## ✨ Features

- 🔐 **User Authentication** — Register and log in securely.
- 🎯 **Career Assessment** — Explore career options based on user interests and skills.
- 💡 **Career Recommendations** — Discover suitable career paths.
- 📊 **Skill Gap Analysis** — Identify skills to improve for a target role.
- 🗺️ **Learning Roadmap** — Organize learning goals into actionable steps.
- 📚 **Courses & Learning Resources** — Explore resources for skill development.
- 📄 **Resume Analyzer** — Review resume information.
- 🤖 **AI Career Chatbot** — Get assistance with career-related questions.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Build Tool:** Vite
- **Authentication & Backend Services:** Firebase
- **AI Integration:** OpenRouter API (where configured)

## ⚙️ Run Locally

### Prerequisites

- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pk0699629-hash/careerpilotAi.git
   ```

2. Open the project folder:

   ```bash
   cd careerpilotAi
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required Firebase settings and API keys using environment variables. Do not commit secret keys to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.
